# .skellspace 0.1 draft

Files describe planned user-editable scenes. In Skell-Afar 0.5.x the DSP uses compiled 20-scene `spaces` and `characters` tables in `Source/dsp/SceneModel.h`; these files are **not** loaded at runtime.

Field units: metres, seconds, Hz and dB. Absorption per octave: 125, 250, 500, 1000, 2000, 4000, 8000 Hz. All procedural beds are original synthesized audio.

Import/export, scene designer and per-band material solver remain planned features.
